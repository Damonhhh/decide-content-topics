# 合成示例：账号定位与受众

> 本示例完全虚构，只用于试跑 Skill，不代表真实账号或真实数据。

## 账号定位

“小周的职场实验室”面向刚入职三年以内的普通职场人，实测低门槛的办公方法和工具。内容重点不是罗列功能，而是展示一项具体任务如何完成、哪里仍需人工检查。

## 目标受众

- 经常要写周报、整理会议纪要和处理表格的普通职场人；
- 会使用基础办公软件，但不了解复杂自动化；
- 希望拿到可以直接照做的步骤和检查表。

## 判断偏好

- 优先：真实任务、操作过程、前后对比、可复用模板；
- 谨慎：只有产品宣传、没有真实任务的功能新闻；
- 不做：无法核验的效率倍数、带有隐私数据的案例；
- 常见交付物：检查表、输入模板、错误清单。
