# decide-content-topics

一套从账号定位走到选题立项的自媒体决策 Skill。

它不是替你批量生成标题，而是把四件容易混在一起的事串成一条流程：账号为谁服务、最近讲过什么、去哪里找信息、这一条到底做不做。缺资料时先给空白问卷或模板，资料齐了再筛信息、查重复、比较候选。最终决定仍由你来做。

## 四个模块

1. **账号定位问卷**：没有定位资料时生成 `00-账号定位问卷.md`；收到答案后整理定位草案，等你确认。
2. **近期内容重复检查**：读取最近 3—10 条内容，生成 `06-近期内容重复检查.md`，避免只换标题或热点外壳。
3. **信息源雷达**：提供一份空白的来源分层模板。你填自己的公开来源；本包不包含作者真实使用的网站、账号、群聊或订阅地址。
4. **选题决策**：从信息快照生成筛选表、候选比较和选题立项卡，并在关键阶段等待人工放行。

## 它会交付什么

- `00-账号定位问卷.md`：仅在定位缺失时生成。
- `02-账号定位与受众.md`：根据问卷回答整理，必须由用户确认。
- `03-近期内容摘要.md`：近期内容缺失时生成空表。
- `01-信息源雷达配置.md`：没有雷达时生成空白配置。
- `04-信息快照.md`：记录来源、时间、可确认事实、来源方主张和证据状态。
- `06-近期内容重复检查.md`：判断新信号与近期内容是高重复、中度相近还是新增。
- `08-信息筛选表.md`：决定每条信息进入候选、继续观察还是淘汰。
- `09-候选选题比较.md`：最多三个候选，包含七项评分、硬闸门和最强反对理由。
- `10-选题立项卡.md`：记录人工选择后的题目、证据边界、观众交付和脚本阶段要求。

账号定位、候选生成和选题立项都有人工确认点。Skill 不会因为分数高就直接替你写稿。

## 快速开始

1. 获取 `decide-content-topics-v0.4.1-skill.zip`，或者直接使用仓库中的 `skill/decide-content-topics/`。
2. 解压后确认 `decide-content-topics` 文件夹里直接包含 `SKILL.md`。
3. 按你所用 AI 客户端的方式导入或放入 Skill 目录。
4. 可以直接说：`用 decide-content-topics 帮我走一遍选题流程。缺什么资料就先生成对应问卷或模板，不要替我填。`

已有定位、近期内容和信息快照时，也可以直接交给它读取。没有真实资料时，可用 [`assets/example-project`](skill/decide-content-topics/assets/example-project) 中明确标注为虚构的案例试跑。

## 判断方法

候选会检查钩子力、观众带走物、具体案例、证据、收藏或追问理由、新增信息和画面可看性。没有完成近期内容重复检查时，不能给“新增信息”打分。

这些情况会直接阻止立项：

- 观众看完拿不走具体东西；
- 只有概念，没有案例和可核验证据；
- 与近期内容高度重复；
- 没有可用画面；
- 证据不足或风险无法控制。

完整规则见 [`scoring-and-gates.md`](skill/decide-content-topics/references/scoring-and-gates.md)。

## 能力边界

- 雷达只采集用户自行配置且允许公开访问的来源；不能访问时，改用用户提供的脱敏信息快照。
- 公开包只包含雷达结构，不包含作者的真实来源清单或私有配置。
- Skill 不负责直接写完整口播稿、制作视频或自动发布。
- 它不保证覆盖所有热点，也不保证一次选出必爆选题。
